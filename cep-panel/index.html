BangCut을 쓰려면 준비가 필요해요

컷편집은 클로드 코드(Claude Code)가 이 맥에서 직접 수행합니다. 아래 두 단계를 마치면 바로 사용할 수 있어요.

1 클로드 데스크톱 / 클로드 코드를 설치하세요
curl -fsSL https://claude.ai/install.sh | bash
2 클로드 코드 설치(권한 무시로 설정 필수) 후 아래 프롬프트를 실행하세요 — 프로젝트 클론과 설치까지 자동으로 진행됩니다
claude --dangerously-skip-permissions "https://github.com/sambang39/BangCut.git 을 클론하고 README의 설치 절차대로 셋업해줘"

기존 영상본이 아닌 새로운 영상본으로 교체하시겠어요?

VITO 전사를 쓰려면 API 키가 필요해요

리턴제로 VITO는 유료 API입니다. 발급은 5분이면 끝나요.

1developers.rtzr.ai에 접속해 가입하세요
2콘솔에서 애플리케이션 생성 → CLIENT_ID / CLIENT_SECRET 발급
3BangCut 설정 탭에 두 키를 입력하고 저장하면 VITO가 활성화됩니다
